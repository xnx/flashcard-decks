# Flashcard decks

Decks of flashcards, as bundles for [django-flashdeck](https://github.com/xnx/django-flashdeck): a subject's decks and cards, with their images, in a `cards.yaml` file. They are used at https://scipython.com/apps/flashcards/.

| Folder | Subject | Decks | Cards |
|---|---|---|---|
| `french` | French | The conjugations of 35 verbs (32 irregular ones, the regular *parler* and *finir*, and the impersonal *falloir*), one deck for each of seven tenses, with reference text on how each tense is formed | 241 |
| `physics` | Physics | The 26 circuit symbols of GCSE Physics, drawn as SVG images, each with a note on what the component does | 26 |

Each bundle is generated by a script beside it (`french/make_verbs.py`, `physics/make_circuit_symbols.py`): change the script, not the `cards.yaml` it writes.

## Using a deck

On a Wagtail site with django-flashdeck, upload a bundle's zip file under *Flashcards → Import and export*; on any site, run `manage.py flashdeck_import` with its folder or zip file. A deck already on the site is updated by importing it again with *Update* ticked (`--update`): its cards change, a card's image is replaced only if it has changed, and learners' progress is kept.

## Changing a deck

1. Change the generator and run it, for example `uv run python french/make_verbs.py`.
2. Check every bundle, by importing it into a throwaway database, and make the zip files in `dist/`:

   ```bash
   uv run python check.py
   ```

3. Commit the script with what it wrote, and open a pull request. CI runs the generators (and fails if what they write differs from what is committed), checks every bundle, and keeps the zip files from each run as an artifact. A tag (such as `v2026.11.11`) attaches them to a release.
4. Upload the zip file to the site, with *Update* ticked.

The French conjugations can also be compared with those of verbecc, a second source (whose tables come from Verbiste):

```bash
uv run --with verbecc python french/check_with_verbecc.py french/cards.yaml
```
